# Coastal Facility Services — Website

Static marketing site for **Coastal Facility Services LLC**, a commercial janitorial and facility services company serving Carlsbad and the Southern California coast.

**Contact:** info@coastalfacilityservice.com · (619) 335-5304
**Headquartered:** Carlsbad, California

---

## Deployment

Drop the contents of this folder at the web root of `coastalfacilityservice.com`. The site is 100% static — no build step required.

- **North County San Diego** — Carlsbad (HQ), Oceanside, Vista, La Jolla, Encinitas, San Marcos, Escondido
